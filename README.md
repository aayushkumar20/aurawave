# Music Player

A modern, sleek web-based music player application.

## Features

- 🎵 Audio playback and playlist management
- 🎨 Modern and responsive user interface
- ⏯️ Playback controls (Play, Pause, Skip, Shuffle, Repeat)
- 📊 Volume and progress controls

## Getting Started

Clone the repository and open `index.html` in your browser or serve it with a local web server.

```bash
git clone https://github.com/aayushkumar20/music-player.git
cd music-player
```
